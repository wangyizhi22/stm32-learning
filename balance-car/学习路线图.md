# STM32 平衡车项目 · HAL 学习路线图

> 你的情况：有 CubeMX + HAL 基础，PID 完全不会，买的课程用**标准库**讲，但每个章节都附了 **HAL 源码**。
> 这份路线图就是帮你绕开「标准库视频」这座山，直接用 HAL 源码把项目学完。

---

## 0. 先记住一个核心心法（最重要，先读三遍）

标准库和 HAL 的区别，**不在于函数名，而在于「初始化放在哪了」**。

| 视频里老师做的事（标准库） | 你这边（HAL） |
|---|---|
| 手写 `RCC_APB2PeriphClockCmd()` 开时钟 | 在 `.ioc` 里点一下，自动生成 |
| 手写 `GPIO_Init()` 配引脚 | 在 `.ioc` 里配引脚，自动生成 `MX_GPIO_Init()` |
| 手写 `TIM_TimeBaseInit()` | 在 `.ioc` 里配定时器，自动生成 `MX_TIM_Init()` |

**所以看 HAL 代码的正确顺序永远是三步：**

1. **先打开 `.ioc`** —— 看老师配了哪个外设、哪个引脚、什么参数（这是标准库视频给不了你的上帝视角）；
2. **再看 `main.c` 里的 `MX_xxx_Init()`** —— 确认上一步的参数变成了哪段代码；
3. **最后看 `user/` 和 `my_lib/`** —— 这才是老师真正手写、需要你理解的业务逻辑。

**视频只看「这一章在干嘛、原理是什么」，代码永远看 HAL 那份，不要跟着视频敲标准库代码。**

## 1. 快速对照表（解决「视频对不上」的痛点）

| 视频标准库函数 | HAL 对应 |
|---|---|
| `RCC_xxxClockCmd()` | `.ioc` 配置，自动生成 |
| `GPIO_Init()` | `.ioc` 配引脚 → `MX_GPIO_Init()` |
| `GPIO_SetBits()` / `GPIO_ResetBits()` | `HAL_GPIO_WritePin(GPIOx, PIN, SET/RESET)` |
| `GPIO_ReadInputDataBit()` | `HAL_GPIO_ReadPin(GPIOx, PIN)` |
| `TIM_Cmd(TIM3, ENABLE)` | `HAL_TIM_Base_Start(&htim3)` |
| `TIM_SetCompare1()` | `__HAL_TIM_SET_COMPARE(&htim1, TIM_CHANNEL_1, x)` |
| `ADC_SoftwareStartConvCmd()` | `HAL_ADC_Start_IT(&hadc1)` |
| `ADC_GetConversionValue()` | `HAL_ADC_GetValue(&hadc1)` |
| `USART_SendData()` | `HAL_UART_Transmit(&huart2, buf, len, timeout)` |
| 串口接收中断 | `HAL_UART_Receive_IT()` + `HAL_UART_RxCpltCallback()` |
| 定时器中断 | `HAL_TIM_PeriodElapsedCallback()` |

> 后面每一章，我会再给你补「这一章专属」的完整对照。

## 2. 总策略：先会用，再懂为什么

1. **先跑通、建立直觉，再补理论。** 6.2～6.8 的拉普拉斯、传递函数、波特图全部先跳过，等你会调 PID 了再回头啃。
2. **一个外设一个小专题。** 用到什么学什么（ADC → PWM → 编码器 → I2C），不要想一口气学完整个 HAL。
3. **每章三步走：看原理（视频/课件）→ 读 HAL 源码 → 自己动手重建一遍。** 最后一步最关键，光看永远学不会。

## 3. 分阶段路线

### 阶段 0 —— 热身：摸清工程骨架（半天）

**目标：** 学会「从 `.ioc` 反推代码」这个技能，能编译烧录一次。

- 打开 `3.2. 【电机】电机调速代码（1）/3.2(1) 源码hal库/.../balance_car/` 这个工程；
- 打开 `balance_car.ioc`，看 CubeMX 里配了哪些外设（ADC1、TIM3、USART2、GPIO）；
- 对着 `main.c` 找到对应的 `MX_ADC1_Init()`、`MX_TIM3_Init()`、`MX_USART2_UART_Init()`；
- 分清哪些是 CubeMX 自动生成（别改），哪些是老师手写的（`user/`、`my_lib/`、`test/`）；
- 编译、烧录，确认车能跑出厂程序。

**验收标准：** 能说清楚 `user/app_bat.c` 里的 `App_Bat_Init()` 和 `main.c` 里的 `MX_ADC1_Init()` 分别是谁写的、谁负责什么。

---

### 阶段 1 —— 第一个外设打通：ADC（第 2 章）

**目标：** 完整走通「配置 → 初始化 → 启动 → 中断回调 → 用数据」这一条 HAL 链路。

**看什么：**
- 2.1 课件（ADC 原理、分压电阻测电压）—— 只看原理；
- `2.1 源码hal库` 里的 `user/app_bat.c`、`Core/Src/main.c`；
- 重点读 `HAL_ADC_ConvCpltCallback()` 这个中断回调，理解「ADC 采完 → 自动进回调 → 取数换算电压」。

**跳过什么：** 视频里的标准库初始化代码，全部用 `.ioc` 代替。

**要掌握的 HAL 知识点：**
- `HAL_ADC_Start_IT()` 启动 ADC + 中断；
- `HAL_ADC_GetValue()` 取采样值；
- `HAL_ADC_ConvCpltCallback()` 回调函数的重写；
- 分压公式：`volt = 采样值 / 4095 * 8.4`（为什么是 4095？为什么乘 8.4？想清楚）。

**练什么（必做）：** 从零新建一个 CubeMX 工程，配 ADC1 采 PA0 上的分压电压，串口把电压值打印出来。

**验收标准：** 拧动电位器/换电压源，串口数字跟着变。

---

### 阶段 2 —— PWM + 电机转起来（第 3 章）

**目标：** 用 PWM 控制 TB6612 驱动电机正转、反转、调速。

**看什么：**
- 3.1 课件（PWM 占空比、H 桥原理）；
- `3.2` HAL 源码里的 `user/app_pwm.c`、电机方向控制 GPIO；
- 重点理解：**占空比决定转速，两个 IO 的电平组合决定方向**。

**要掌握的 HAL 知识点：**
- `HAL_TIM_PWM_Start()` 启动 PWM 输出；
- `__HAL_TIM_SET_COMPARE()` 改占空比；
- `HAL_GPIO_WritePin()` 控制方向引脚。

**练什么（必做）：** 让电机先正转 2 秒 → 停 → 反转 2 秒，然后用按键或串口指令调速。

**验收标准：** 电机能正反转、能无级调速，你能解释「为什么改 COMPARE 值就是改转速」。

---

### 阶段 3 —— 编码器读转速（第 4 章）

**目标：** 用定时器编码器模式读出电机的实时位置和转速。

**看什么：**
- 4.1～4.3 课件（编码器原理、减速比）；
- 4.4 M 法测速 HAL 源码；4.5～4.6 T 法测速了解即可，先不深究；
- 重点理解：**编码器模式本质是定时器对外部脉冲自动计数，你只需定期读计数值再除以时间就是速度**。

**要掌握的 HAL 知识点：**
- `.ioc` 里配置 TIM 为 Encoder Mode（编码器模式）；
- `HAL_TIM_Encoder_Start()`；
- `__HAL_TIM_GET_COUNTER()` 读计数值；
- 减速比的作用（电机转一圈，输出轴转多少圈）。

**练什么（必做）：** 在阶段 2 的基础上加上编码器，串口实时打印电机转速（转/分钟）。

**验收标准：** 手拨动电机，转速显示跟着变；能解释「计数值差 ÷ 时间」怎么换算成转速。

---

### 阶段 4 —— PID 直觉（第 6 章，跳着学）⭐ 你的重点

**目标：** 会用 PID 把电机转速稳定在一个设定值上，不碰那堆数学。

**看什么：**
- 6.1 课件（PID 是什么）；
- **跳过 6.2～6.8**（建模、拉普拉斯、波特图，后面回头补）；
- 6.9 三段论、6.10 控制器程序 HAL 源码、6.11 测试。

**先建立三个直觉（不背公式，记住「感觉」）：**
- **P（比例）**：离目标越远，使的劲越大。P 太小→到不了目标；P 太大→来回震荡。
- **I（积分）**：把「一直差一点点」的误差累积起来，最终消除那点偏差。但会让系统变慢、易超调。
- **D（微分）**：预测「要冲过头了」，提前踩刹车，抑制震荡和超调。

**要掌握的 HAL 知识点：** 这一章 HAL 基本没新东西，就是把阶段 3 的测速 + 阶段 2 的 PWM 用 PID 公式串起来，周期性地跑在 `main` 循环或定时器中断里。

**练什么（必做）：**
1. 先只调 P，看转速「够不着 → 震荡」的整个过程；
2. 加一点 D，看震荡被压下去；
3. 再加一点 I，看稳态误差被消除；
4. 用 VOFA+（Mac 用不了就让我帮你写 Python 画图脚本）看波形，记录 Kp/Ki/Kd 变化对波形的具体影响。

**验收标准：** 设定 1000 转/分，实际转速能又快又稳地到 1000，超调小、不震荡；你能用大白话讲清楚「Kp 调大点会发生什么」。

---

### 阶段 5 —— 姿态 + 倒立摆串级 PID（第 5、7 章）

**目标：** 读 MPU6050 得到姿态角，用串级 PID 让车立起来。

**看什么：**
- 5.1～5.2 课件（MPU6050 原理）；
- 5.3 寄存器读写 HAL 源码（I2C 通信）；
- 5.4～5.6 欧拉角解算（先会用，数学细节可后补）；
- 7.1 串级 PID、7.6 参数整定、7.7 代码。

**要掌握的 HAL 知识点：**
- `HAL_I2C_Mem_Read()` / `HAL_I2C_Mem_Write()` 读 MPU6050 寄存器；
- 理解**串级 PID = 两个 PID 套在一起**：内环（角速度/速度）快、外环（角度/位置）慢，外环的输出是内环的目标。

**练什么（必做）：** 先把 MPU6050 角度读出来在串口/上位机上看，确认姿态对了，再套串级 PID。

**验收标准：** 车能自己立住，推一下能自己回正。

---

### 阶段 6 —— 速度环 + 遥控器（第 8、9 章）

**目标：** 让车不仅能立，还能按遥控指令前进、后退、转向。

**看什么：**
- 8.1～8.4 速度环；
- 9.1 串口接收字符串、9.2 指令解析、9.3 转向和速度控制。

**要掌握的 HAL 知识点：**
- `HAL_UART_Receive_IT()` 串口中断接收 + `HAL_UART_RxCpltCallback()`；
- 简单字符串协议解析（收到什么指令 → 改哪个目标量）。

**验收标准：** 用串口助手（或手机 app）发指令，车能前进后退转向。

---

### 阶段 7（可选，回头补理论）—— 第 6.2～6.8

等你 4、5、6 阶段都跑通了，再回头看建模、拉普拉斯变换、传递函数、波特图。**这时候你会调 PID 了，再看数学，会有「原来如此」的感觉，而不是被劝退。**
